# Optimization Algorithms

This project implements and compares a range of numerical optimization algorithms for least-squares problems.

The methods are tested on numerical problems of increasing dimension, with experiments comparing their convergence behaviour and computational performance.

## Methods

* Gradient descent with constant step size
* Gradient descent with exact line search
* Gradient descent with Armijo line search
* Conjugate gradient
* Quasi-Newton methods
* Polyak's Heavy Ball method
* Nesterov acceleration
* Incremental stochastic gradient descent
